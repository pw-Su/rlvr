# RLVR 训练框架

一个用于强化学习（RL）训练的端到端框架，演示智能体如何通过调用 API 完成任务并获得多维度稠密奖励。

## 快速开始

### 1. 安装依赖
确保已安装 Python 3.8+，然后安装所需依赖：

```bash
pip install -r requirements.txt
```

### 2. 运行演示
运行标准演示，智能体将查询 Top N 消费者并输出评分结果：

```bash 
python main.py

```

### 3. 预期输出
运行标准演示，智能体将查询 Top N 消费者并输出评分结果：

```bash
python main.py --test
```

### 4. 其他参数
--top-n N：指定查询的消费者数量（默认为 3）
--json：以 JSON 格式输出结果，便于脚本解析

```bash
# 查询 Top 5 并以 JSON 格式输出
python main.py --top-n 5 --json
```

## 设计说明
### 任务的设计思路
本任务要求智能体查询最近 N 天内消费总额最高的前 K 名用户，并返回用户 ID、消费总额、品类数量和排名，选择这一任务是因为它输出结构化、结果可精确验证、难度适中且贴近真实的数据分析场景，既能考察智能体的 API 调用能力，又便于用确定性规则计算奖励。

### 多步 API 调用的必要性及数据依赖关系
智能体需要先调用 `/users/top_spenders` 获取用户 ID 和总金额，再对每个用户调用 `/users/{user_id}/categories` 获取品类数，最后组装结果，这种串行依赖模拟了真实业务中"先筛选、再详情查询"的模式，迫使智能体学会规划调用顺序和组装多源数据，比单步调用更能锻炼多步推理能力。

### 奖励计算逻辑
奖励引擎采用四个维度的稠密奖励综合评分：用户集合（召回率，权重 40%）、消费金额（相对误差，权重 30%）、排名顺序（位置匹配率，权重 20%）、品类数量（准确率，权重 10%），各维度得分乘以权重后求和得到 0.0~1.0 的总分，部分正确也能获得部分分数，提供平滑的梯度信号以加速 RL 收敛。

### 该任务适用的 RLVR 训练场景
本任务适用于工具调用训练（学习选择工具和规划调用顺序）、结构化输出训练（生成符合 schema 的 JSON）、多步推理训练（拆解子任务并组装结果）、奖励模型验证（用确定性规则验证奖励模型打分）以及课程学习（通过调整 TOP_N 和 RECENT_DAYS 渐进式提升难度），但不适用于开放域问答、创意生成等答案不唯一或奖励难以量化的场景。
